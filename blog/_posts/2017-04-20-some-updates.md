Hey pals,

I've been silent on social media for a few months now, so I figured I'd write something up about what I've been up to. Also blogging is cool and it seems like all academics love doing it, and I'm an academic now so here we go.

- In May, I'm presenting our paper "MON: Mission-optimized Overlay Networks" (my first paper!!) at INFOCOM in Atlanta. We looked at designing an overlay network which decides which traffic to route and how much bandwidth to allocate traffic. There's a tradeoff here between building a centralized system which solves the problem well but is not particularly resiliant and a distributed system which solves the problem inexactly but which is more resilient. We did some cool trickery with TCP to make the distributed system interact well with the centralized system. Check it out on [arXiv](http://arxiv.org/abs/1701.08098)
- Also in May, I'm graduating from UMass with a master's in computer science. I've written a thesis about some algorithms for inferring the capacity of a network, which I think is pretty neat. UMass has been super awesome, but it's time for me to move on.
- Speaking of moving on, in September, I'm starting a PhD at Stanford! If you're in the bay area, hopefully I'll be seeing a lot more of you.
